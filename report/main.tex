\begin{abstract}
This report presents \emph{Aion's Edge}, a course project for
``Multi-Criteria Optimization and Decision Analysis''. The project turns
three course topics into a small strategy game: linear programming,
multi-objective optimisation, and voting-based decision analysis. The
report explains the design of the game, the operations research ideas
behind each level, and the development process shown by the git history.
The main result is that the project works both as software and as a
compact demonstration of how optimisation and collective choice can be
made visible through gameplay. The current public deployment is available
at \url{https://aion-s-edge.streamlit.app/}.
\end{abstract}
